# Room studio editor

Use snap placement for original surfaces, or free placement for normalized coordinates and intentional overlap. Each piece has optional rotation, layer and rendering preferences; old rooms keep their original placement. The studio has editable wall and floor finishes, floor patterns, lighting, built-in furniture visibility and contact shadows. All appearance and placement properties are optional on existing version-1 saves and validated before persistence. PNG exports use the same artwork bounds, positions, depth, rotation and backdrop. Zoom is an editor-only control.
