# Charcoal interface

Boop’s website defaults to a white canvas. Open **Settings → Appearance** to choose Light or Dark. The site remembers the choice in the current browser.

Dark mode uses Boop’s charcoal palette with blue actions, mint progress accents, and gold coin values. The craft board is #1b1e24, the app canvas #15171b, and panels #20242b. The Android shell with its native toolbar continues to use charcoal.
